## 🌐 About | درباره پروژه

**English**

LIMINI ICONS is a web-based icon library designed to make finding and customizing icons easier. It brings together multiple icon collections in one searchable interface, allowing users to browse categories, customize icon appearance, and download icons in different formats.

With Persian-friendly search and a clean interface, it provides a convenient resource for designers and developers.

**فارسی**

LIMINI ICONS یک کتابخانه آنلاین آیکون است که با هدف ساده‌تر کردن جستجو، انتخاب و شخصی‌سازی آیکون‌ها طراحی شده است.

این ابزار مجموعه‌های مختلف آیکون را در یک محیط یکپارچه گردآوری می‌کند و به کاربران امکان می‌دهد آیکون‌های موردنظر خود را بر اساس دسته‌بندی یا جستجو پیدا کنند، ظاهر آن‌ها را تغییر دهند و با فرمت‌های مختلف دریافت کنند.

## 🎯 Icon Collections | مجموعه‌های آیکون

LIMINI ICONS combines multiple icon collections into a unified library.

این ابزار از چندین مجموعه آیکون استفاده می‌کند و آن‌ها را در یک محیط یکپارچه در دسترس قرار می‌دهد.

## 🚀 How to Use | راهنمای استفاده

1. Open LIMINI ICONS in your browser.
2. Browse icon categories or search for an icon.
3. Adjust its color and size.
4. Copy the SVG code or download it as SVG or PNG.

---

۱. وارد کتابخانه آیکون شوید.
۲. از طریق دسته‌بندی‌ها یا جستجو، آیکون موردنظر را پیدا کنید.
۳. رنگ و اندازه آیکون را تغییر دهید.
۴. کد SVG را کپی کنید یا خروجی SVG و PNG بگیرید.
